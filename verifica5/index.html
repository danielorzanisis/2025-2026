Massimi della matrice

Crea una funzione che riceve una matrice di numeri interi e costruisce una nuova matrice della stessa dimensione.
Nella nuova matrice:
  • inserisci 1 nelle posizioni in cui compare il valore massimo della matrice originale;
  • inserisci 0 in tutte le altre posizioni.
Esempio:
matrice_input =
[[5, 2, 8],
[1, 8, 3],
[4, 6, 7]]

matrice_output =
[[0, 0, 1],
[0, 1, 0],
[0, 0, 0]]

Cornice della matrice

Crea una funzione che riceve una matrice di numeri interi e costruisce una nuova matrice della stessa dimensione.
Nella nuova matrice:
  • gli elementi sul bordo (prima riga, ultima riga, prima colonna e ultima colonna) devono mantenere il valore originale;
  • tutti gli altri elementi devono essere sostituiti con 0.
Esempio:
matrice_input =
[[2, 7, 5, 1],
[10, 1, 3, 4],
[4, 8, 3, 2],
[0, 2, 7, 9]]

matrice_output =
[[2, 7, 5, 1],
[10, 0, 0, 4],
[4, 0, 0, 2],
[0, 2, 7, 9]]
